# Фоны, CG и 18+

[← Вики](README.md)

Лагерь, пляж, столовая, лодочная станция, остановка «410»… Все фоны игры — у тебя под рукой.

## Фон

```
фон ext_square_day fade
```

Новый фон убирает всех героев. Чтобы герои остались на месте — `сменитьфон ext_square_night`.

Вкладка **«Фоны»** → листай плитки или ищи словом: `square`, `beach`, `night`, `dining`… Наведи — фон уже в кадре.
Время суток в названии фона (`_day`, `_sunset`, `_night`) — а героев под него перекрашивает `время день / вечер / ночь`.

## CG

```
цг d3_sl_evening dissolve
```

Рисованная сцена на весь экран. Вкладка «Фоны» → **«CG»**.

## 18+

Вкладка «Фоны» → красная кнопка **«18+»**. Там всё, что вырезали из Steam-версии: CG из 18+ патча, старые карточки
дней и старые тела героинь.

- Патч **«Deleted hentai scenes»** (автор — Лена) **встроен в GenryBL**. Подписываться не надо, превью работают сразу.
- CG, которые ты покажешь в моде, **GenryBL кладёт прямо в мод**. Игрок увидит их, даже если патча у него нет.
- Не хочешь, чтобы через плечо подсмотрели, — **«Размытие: вкл»**: превью размываются.
- Кнопки «Патч в Мастерской» и «Автор патча» — поставь автору лайк, он заслужил.

## Свои картинки

**«＋ Свой»** во вкладке «Фоны» — выбери картинку, она ляжет в мод, и её можно показывать как любой фон:
`фон мой_фон` или `цг моя_сцена`. Кнопка **«Папка мода»** откроет папку, куда всё складывается.

## Кинозум

```
кинозум cg d3_sl_evening 6 1.5 0.5 0.3
```

Камера медленно наезжает на точку картинки: 6 секунд, в 1.5 раза, в точку (0.5 по горизонтали, 0.3 по вертикали).
Для драмы — самое то.
