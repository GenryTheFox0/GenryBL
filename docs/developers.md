# Для разработчиков

[← Вики](README.md)

Хочешь покопаться в коде, починить баг или добавить фичу — тебе сюда. Тут без техно-стеснения.

## Что это внутри

- **C++17 + Qt 6.8** (Quick/QML, Multimedia, Concurrent), сборка — **CMake + Ninja**, компилятор — **MSVC 2022**.
- GenryBL **не копирует игру**: читает её `archive.rpa` и архивы Мастерской напрямую (свой читатель RPA), рисует
  кадр сам, а мод компилирует в обычный Ren'Py-скрипт `game/mods/<id>/<id>.rpy` + картинки, которые мод использует.
- Интерфейс — QML, ядро — чистый C++ без UI, его же используют консольная утилита и самотест.

```
src/core/     ядро: компилятор истории → Ren'Py, превью кадра, lint, читатель RPA и Мастерской,
              гардероб, кино-режим, сборка мода, телефон, погода, оверлеи
src/app/      Engine (мост C++ ↔ QML), установщик/удалятор, провайдеры картинок
qml/          весь интерфейс: главное меню в стиле БЛ, редактор, мастера, установщик
data/         каталог игры (es_catalog.json), формы команд (forms.json), шаблон мода, общие списки гардероба
tools/        gb_selftest (самотест), gb_cli (консоль), setup_boot (загрузчик установщика),
              make_release.py, bundle_patch.py, harvest_wardrobe_lists.py
tests/golden/ эталонные истории и их Ren'Py-выход — компилятор сверяется с ними
docs/         эта вики
```

## Собрать

Нужно:

- Windows 10/11, **Visual Studio 2022** с «Разработкой классических приложений на C++»;
- **Qt 6.8** для MSVC 2022 64-bit (модули Quick, Multimedia);
- **CMake ≥ 3.21** и **Ninja**;
- «Бесконечное лето» из Steam — без него нечего превьюшить и тестировать.

Из «x64 Native Tools Command Prompt for VS 2022»:

```bash
cmake -S . -B build -G Ninja -DCMAKE_BUILD_TYPE=Release -DCMAKE_PREFIX_PATH=C:/Qt/6.8.3/msvc2022_64
cmake --build build
```

Получишь `build/GenryBL.exe`, `build/gb_selftest.exe`, `build/gb_cli.exe`, `build/GenryBL_Setup.exe`.
Программа ищет папку `data` вверх от своего exe, так что из `build/` она найдёт `data/` репозитория. Для запуска
положи Qt в `PATH` (или прогони `windeployqt`).

Это **сборка разработчика**: у неё в углу плашка «сборка разработчика», а то, что ты удалишь или поправишь в
гардеробе, пишется прямо в `data/wardrobe_*.txt` — и уедет в следующий релиз. Публичная сборка — с
`-DGB_RELEASE=ON`: свои правки пользователь хранит у себя в `work/`.

## Самотест

```bash
build/gb_selftest.exe
```

Под сотню проверок: компилятор против эталонов, превью, гардероб, 18+ патч, кино-режим, установщик. Игру ищет сам
через Steam; если не нашёл — задай `GENRYBL_ES` (папка с `Everlasting Summer.exe`). **Перед pull request самотест
должен быть зелёным.**

`gb_cli` — то же ядро из консоли: `gb_cli wardrobe <story.txt> dv` покажет наряды Алисы из твоих подписок,
`gb_cli cinema <story.txt>` пройдёт мод как кино-режим.

## Релиз

```bash
python tools/make_release.py
```

Собирает публичную сборку (`-DGB_RELEASE=ON`), гоняет самотест, раскладывает `dist/stage/GenryBL`
(программа + Qt + Visual C++ рядом с exe + ffmpeg + 18+ патч), через `dumpbin` доказывает, что каждой DLL хватает
того, что внутри, и пакует `dist/github`: `GenryBL_Setup.exe` и portable zip.

- `GENRYBL_QT` — где Qt, если не по умолчанию.
- ffmpeg кладётся в `third_party/ffmpeg/` (в репозиторий не входит — возьми essentials-сборку с gyan.dev).
- 18+ патч `tools/bundle_patch.py` берёт из Мастерской (нужно один раз на него подписаться) и кладёт в `data/patch/`
  — без Ульяны и Электроника.

## Правила, которые не обсуждаются

- **Никакого 18+ с Ульяной и другими «детскими» персонажами.** Такой PR закрывается сразу.
- Код — **GPL-3.0**. Присылая PR, ты соглашаешься, что он уходит под эту лицензию.
- Интерфейс и тексты для людей — по-русски и по-человечески. Комментарии в коде — английский, как уже принято.
- Не ломай эталоны молча: если выход компилятора меняется намеренно — обнови `tests/golden` и объясни в PR, почему.
