# Музыка, звук и видео

[← Вики](README.md)

Без «Everlasting Summer» на фоне это не БЛ. Вся музыка и звуки игры — тут, плюс любые твои.

## Музыка игры

```
музыка everlasting_summer
музыка meet_me_there fadein 4
стопмузыка
```

Вкладка **«Звук»** → нажми ▶ на треке — послушаешь прямо в конструкторе. Трек зацикливается и плавно входит сам.
Несколько подряд — `очередьмузыки …`. Экран-плеер, где игрок сам выбирает трек, — `музплеер …`.

## Звуки и атмосфера

```
звук sfx_bush_leaves
атмосфера …
стопвсе
```

Атмосфера — фоновый шум места: лагерь днём, ночной лес, пляж, столовая.

## Свои файлы

Кидай **любой формат**: mp3, wav, flac, m4a, mp4, avi… GenryBL сам переделает их в формат игры и подберёт нормальное
качество. ffmpeg уже внутри — ничего ставить не надо.

```
музыкафайл моя_песня.mp3
звукфайл бах.wav
озвученнаяреплика Алиса | alisa_01.ogg | Ну привет.
```

Озвучить сцену целиком удобнее через **«Диалог»** (Ctrl+D): реплики таблицей, файлы озвучки — по порядку.

![Диалог и озвучка](images/screens/dialogue.jpg)

## Видео

```
видео opening.ogv
видеофон мой_ролик.mp4
стопвидеофон
```

`видео` — ролик на весь экран (заставка игры или свой). `видеофон` — видео вместо фона, а поверх идут реплики.
