# Шпаргалка команд

[← Вики](README.md)

Всё, что умеет GenryBL, одной страницей. Распечатай и повесь над кроватью, как вожатая — распорядок дня.

Все команды пишутся по-русски, одна на строку. Помнить их не надо: во вкладке **«Команды»** каждая открывается
формой с полями — заполнил, нажал «Вставить». Кнопка **«Настроить строку»** открывает такую же форму для строки,
на которой стоит курсор. А при наборе программа сама подсказывает продолжение.

`[в скобках]` — необязательная часть. `переход` в конце строки — как появиться: `fade`, `dissolve`, `fade2`, `fade3`,
`dspr`, `pixellate`.

## Сцены и переходы

| Команда | Что делает |
|---|---|
| `: утро в лагере` | начало сцены (название можно по-русски) |
| `переход площадь` | уйти в другую сцену насовсем |
| `вызов хаб` | сходить в сцену и вернуться сюда, когда она кончится |
| `конецсцены` | вернуться туда, откуда сцену вызвали |
| `конецигры` | финал мода |
| `пауза 2` | кадр замирает на 2 секунды |

## Фон и CG

| Команда | Что делает |
|---|---|
| `фон ext_square_day fade` | новый фон, все герои уходят |
| `сменитьфон ext_square_night` | сменить фон, герои остаются |
| `цг d3_sl_evening dissolve` | рисованная сцена на весь экран |
| `кинозум <картинка> 6 1.5 0.5 0.3` | камера медленно наезжает на точку картинки (секунды, во сколько раз, точка) |
| `время вечер` | перекрасить героев под день / вечер / ночь, как в игре |

Подробнее — [Фоны, CG и 18+](backgrounds.md).

## Персонажи

| Команда | Что делает |
|---|---|
| `показать dv smile pioneer left dissolve` | показать героя: кто, эмоция, одежда, где, как |
| `показать dv smile pioneer румянец пот left` | то же — с румянцем и потом (ещё: `слёзы`, `мокрая`) |
| `зеркало …` / `крупно …` / `полныйрост …` | отзеркалить, крупный план, во весь рост |
| `входслева dv smile pioneer left 1.5` / `входсправа …` | войти из-за края экрана |
| `идти …`, `призрак …`, `пульс …` | пройти по экрану, полупрозрачный призрак, пульсация |
| `убрать dv dissolve` | убрать героя |
| `выходслева dv 1` / `выходсправа dv 1` | уйти за край |
| `убратьвсех` | убрать всех |
| `фокус dv smile pioneer \| sl normal pioneer` | спор двоих: говорящий ярче и ближе |
| `массовка …` | до 10 героев в ряд, расставятся сами |

Коды героев, эмоции, одежда и позиции — [Персонажи и гардероб](characters.md).

## Реплики и текст

| Команда | Что делает |
|---|---|
| `Алиса: Ну и чего ты встал?` | реплика героя |
| `текст Солнце жарило нещадно.` | рассказчик |
| `крик Алиса \| сильно \| СТОЙ!` | реплика с тряской экрана |
| `озвученнаяреплика Алиса \| alisa_01.ogg \| Привет` | реплика со своей озвучкой |
| `персонаж vs Вожатая #ff8800` | свой говорящий: код, имя, цвет — дальше пиши `Вожатая: …` |
| `заметка …`, `монолог …`, `дневник …`, `воспоминание …`, `большойтекст …`, `мысль …` | текст поверх кадра |
| `окно нуар` / `окноскрыть` / `окнопоказать` | вид окна текста, спрятать и показать |
| `nvlначать` … `nvlконец` | текст страницей на весь экран, как в книге |

## Музыка, звук, видео

| Команда | Что делает |
|---|---|
| `музыка everlasting_summer` | трек игры (зациклен, плавно входит) |
| `музыкафайл мой_трек.mp3` | свой трек из папки мода |
| `очередьмузыки …` | несколько треков подряд |
| `звук sfx_bush_leaves` / `звукфайл бах.wav` | звук игры / свой |
| `атмосфера …` | фоновый шум места: лагерь, лес, пляж… |
| `стопмузыка`, `стопзвук`, `стопатмосфера`, `стопвсе` | тишина |
| `музплеер …` | экран-плеер, игрок сам выбирает трек |
| `видео opening.ogv` / `видеофон …` / `стопвидеофон` | ролик на весь экран / видео вместо фона |

Свои файлы любого формата программа сама переводит в формат игры. Подробнее — [Музыка, звук и видео](sound.md).

## Эффекты кадра

| Команда | Что делает |
|---|---|
| `погода снег` / `погода стоп` | снег, дождь, листья, сердечки, искры, пыль |
| `фильтр сепия` / `затемнить 0.5` / `свет` | цвет кадра, приглушить под текст, вернуть свет |
| `помехи`, `vhs`, `глитч`, `сонныйэффект`, `эффектпамяти` | помехи и сны |
| `флешбэк` … `конецфлешбэка` | флешбэк целиком: полосы, сепия, лёгкие помехи |
| `закрытьглаза`, `открытьглаза`, `моргнуть`, `сонныеглаза` | глаза героя, как в игре |
| `тряска 0.5 3`, `вспышка` | удар / фото, молния |
| `параллакс` / `параллакс выкл` | 3D-режим: кадр оживает от мыши |
| `эффект dissolve` | общий переход для всего, что изменилось выше |

## Надписи, заставки, титры

| Команда | Что делает |
|---|---|
| `титр Глава 1` | заставка: название крупно по центру на чёрном, без плашки диалога |
| `скачок 3 дня` | «Прошло 3 дня» |
| `табло …` | вокзальное табло, буквы перещёлкиваются |
| `новаяглава …` | новая глава (и строчка на экране глав) |
| `день …` / `главаpng …` | заставка дня, как в игре, или своя |
| `роллтитры …` | титры снизу вверх |

## Выборы, очки, память

| Команда | Что делает |
|---|---|
| `выбор` … `конецвыбора` | развилка, варианты `- текст -> сцена` |
| `установить trust 0` / `прибавить trust 1` | очки и переменные |
| `постоянная …` / `постоянноеочко …` | живёт между прохождениями (открыть рут после финала) |
| `если trust >= 2 -> good_end` | условие → сцена |
| `еслипредмет ключ -> дверь` / `еслипостоянная …` | проверить предмет / постоянную |
| `запомнит Алиса \| флаг=помог_алисе` | «Алиса это запомнит» |
| `шкала love_dv \| Алиса \| #ff7a00 \| 0 \| 10` | шкала отношений |
| `шкалы` / `шкалы кнопка` | экран всех шкал / кнопка в углу |
| `лучшаяшкала …` | концовка по самой высокой шкале |
| `предмет ключ \| Ключ от склада` / `убратьпредмет ключ` | инвентарь |
| `инвентарь` / `инвентарь кнопка` | экран сумки |
| `ачивка first_kiss \| Первый поцелуй` | достижение |
| `галерея_разблокировать …` / `реплей …` | открыть CG в галерее / сцену для повтора |
| `уведомление Лена запомнит этот вечер \| Лагерь` | плашка сбоку |

Подробнее — [Выборы, очки и концовки](choices.md).

## Экраны и меню

| Команда | Что делает |
|---|---|
| `экранменю …` | меню-хаб на весь экран: кнопки → сцены |
| `карта square: square @sl, beach: beach` | карта лагеря: место → сцена, кто там нарисован |
| `менюмода …` … `конецменюмода` | своё главное меню мода |
| `главы`, `галерея`, `достижения`, `память` | открыть экран мода посреди истории |

## Телефон

| Команда | Что делает |
|---|---|
| `телефонначать Славя` … `телефонконец` | переписка с кем-то |
| `смс Славя: Вы где?` / `смс я: Скоро будем` | сообщение от неё / от героя |

| `пост …`, `коммент …`, `пуш …`, `лента`, `рабочийстол` | соцсеть, уведомления, экраны телефона |
