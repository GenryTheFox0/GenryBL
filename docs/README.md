# Вики GenryBL

**GenryBL** (Конструктор БЛ) — бесплатная программа с открытым кодом для создания модов к визуальной новелле
«Бесконечное лето». История пишется по-русски, как обычный текст; программа показывает кадр игры вживую, сама
собирает мод и запускает его в игре на нужной сцене.

### Коротко об истории

Всё началось с **GenryModEngine** — первого конструктора Генри на Python с простыми окошками. Он работал, но упирался
в потолок: ни живого превью, ни нормального редактора. Тогда конструктор переписали с нуля на C++ и Qt 6 — так
появился **GenryBL V1**, а старый движок стал для него эталоном: новый обязан собирать моды не хуже. За три месяца
к нему приросли кино-режим, «пиши как сценарий», телефон, карта лагеря, гардероб Мастерской и установщик в стиле
игры. 28 сентября 2026 года вышла V1.0, а код открыт для всех.

Вики объясняет, как сделать свой мод, простым языком и по шагам. Начни с первых двух страниц, остальное открывай,
когда понадобится.
